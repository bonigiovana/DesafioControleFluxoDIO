# 🧮 Desafio de Projeto: Controle de Fluxo em Java

Projeto desenvolvido durante a **Trilha Java Básico da DIO**.

---

## 📌 Sobre o Projeto

O objetivo do sistema é receber dois números inteiros via terminal e realizar a contagem e impressão incremental dos números com base no intervalo entre eles.

### 🛠️ Conceitos Aplicados:
* ✅ **Estruturas condicionais e laços de repetição (`for`)**
* ✅ **Criação e tratamento de exceções customizadas (`try-catch` / `throw`)**
* ✅ **Versionamento de código e publicação no GitHub com Git**
